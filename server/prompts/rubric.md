**CONTEXT: What is a Rubric?**
A rubric is an evaluation tool used to assess performance across multiple criteria. Each standard (criterion) has multiple score levels (typically 1-5), and each score level describes what performance looks like at that level.

**SCORING LEVELS (1-5 Scale):**
- **Level 1**: Poor/Unsatisfactory - Significant deficiencies, major improvements needed
- **Level 2**: Below Average - Notable gaps, substantial improvement required
- **Level 3**: Average/Adequate - Meets basic expectations, room for growth
- **Level 4**: Good/Above Average - Exceeds expectations in most areas
- **Level 5**: Excellent/Outstanding - Exceptional performance, exemplary execution

**RUBRIC COMPLETION PRINCIPLES:**

1. **Be Specific and Observable:**
   - Describe concrete, observable behaviors
   - Use action verbs (demonstrates, articulates, maintains, etc.)
   - Avoid vague terms like "good" or "bad"
   - Include specific examples where helpful

2. **Progressive Differentiation:**
   - Each level should be clearly distinct from adjacent levels
   - Level 1 should describe minimal/poor performance
   - Level 5 should describe exceptional/expert performance
   - Levels 2-4 should show clear progression

3. **Contextual Relevance:**
   - Tailor criteria to the specific rubric context
   - Consider the target audience (managers, employees, etc.)
   - Align with real-world professional scenarios

4. **Actionable Language:**
   - Focus on what the person does or demonstrates
   - Make it clear what differentiates each level
   - Help evaluators easily identify the appropriate level

5. **Consistency Across Standards:**
   - Maintain similar level of detail across all standards
   - Use consistent language and structure
   - Ensure standards work together as a cohesive evaluation system

**EXAMPLE RUBRIC STANDARD:**

Standard: "Active Listening"

- **Level 1**: Frequently interrupts, shows little acknowledgment of what others say, misses key points, demonstrates minimal engagement through body language or verbal responses.

- **Level 2**: Occasionally interrupts, provides some acknowledgment but misses important details, shows inconsistent engagement, struggles to paraphrase or reflect back what was said.

- **Level 3**: Allows others to speak without interruption, acknowledges key points, demonstrates basic engagement through nodding or brief responses, can paraphrase main ideas when prompted.

- **Level 4**: Actively demonstrates listening through body language and verbal cues, asks clarifying questions, accurately paraphrases and reflects back what was said, shows genuine engagement and understanding.

- **Level 5**: Exemplifies exceptional listening skills by deeply engaging with speakers, asking insightful follow-up questions, synthesizing complex information, making meaningful connections, and creating an environment where others feel truly heard and understood.

**QUALITY REQUIREMENTS:**

- **Comprehensive**: Each score level description should be 1-3 sentences that fully capture the performance at that level
- **Clear Differentiation**: Someone reading adjacent levels should immediately understand the difference
- **Professional Tone**: Use professional, objective language suitable for workplace evaluations
- **Practical Application**: Make it easy for evaluators to match observed behavior to a score level
- **Balanced Coverage**: Give appropriate attention to all levels, not just extremes
